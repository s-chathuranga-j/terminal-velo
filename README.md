# Velo

A fast terminal with just enough AI: every command and its output is a block you can select,
copy, search and rerun; autosuggestions come from your history, per folder; and AI help uses the
subscriptions you already have (Claude Code, Codex, Antigravity, Cursor, or local Ollama).
Nothing runs without you pressing Enter, and secrets are redacted before anything is sent.

## Download

Get the latest version from **[Releases](https://github.com/s-chathuranga-j/terminal-velo/releases/latest)**:

| Platform | File |
| --- | --- |
| macOS (Apple silicon and Intel) | `Velo_<version>_universal.dmg` |
| Windows | `Velo_<version>_x64-setup.exe` (or the `.msi`) |
| Linux | `.AppImage`, `.deb` or `.rpm` |

- **macOS:** the app is self-signed. The first time, right-click Velo.app → Open.
- **Windows:** SmartScreen may warn about an unknown publisher → More info → Run anyway.

Installed copies update themselves (Settings → General → Updates).

## In your editor

Velo also runs as a panel in VS Code, Cursor, Windsurf and VSCodium, and as a tool window in
JetBrains IDEs (IntelliJ IDEA, PyCharm, WebStorm, Android Studio, …). The app offers to add it to
the editors it finds; Settings → Editors adds it later.
